General Configuration
Master toggle enables or disables manual number entry for all transaction modules at once. You can also turn individual module access ON or OFF below.
INDIVIDUAL MODULE MANUAL ACCESS CONTROL:
If enabled, the 'Against Bill' field in the Member Receipt Entry screen will be auto-selected based on the receipt's date/month, and the Auto Select button will display ON (read-only). If disabled, it will display OFF and allow the user to write/type the Bill number manually.
If enabled, the Manual Mode toggle and Manual Entry button will display on the Member Receipt Reversal screen to allow switching manual entry ON/OFF per transaction. If disabled, manual entry controls will be hidden.
If enabled, the "PO Mode:" toggle button will be visible on the Payment Entry form to allow selecting Purchase Orders. If disabled, the PO Mode toggle button will be hidden.
If enabled, accounts under Assets -> Cash & Bank Balance will be visible and selectable in Journal Voucher (JV). If disabled (default), Cash & Bank Balance accounts are hidden from Journal Voucher.
If enabled (ON), accounts can also be selected directly by clicking or editing the 'Account Name' column in transaction entry table grids. If disabled (OFF), accounts can only be selected using the 'SELECT ACCOUNT' dropdown/header control above the grid.
7. INDIVIDUAL MODULE ACCOUNT GROUPS VISIBILITY ('SELECT ACCOUNT') [TRANSACTION / OTHER RECEIPT ENTRY (RV), PAYMENT ENTRY (PV), PURCHASE ORDER (PO)]
Configure account group visibility individually for Other Receipt Entry (RV), Payment Entry (PV), and Purchase Order (PO). Disabling a group for a module hides its accounts in that module's 'Select Account' dropdown and Lookup modal.
